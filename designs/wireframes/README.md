# ecom AI Studio 统一详细线稿

## 唯一入口

打开 `workbench-home-layout-options.html`。工作台与全站详细页已经合并到这一个 HTML，不再依赖第二个线稿文件。

统一线稿包含 19 个视图：

- 工作台首页及其 9 个诊断、行动与数据边界视图
- 商品资产、文案与分镜、图片处理工坊、运营数据看板
- 竞品情报、任务队列、商品管理、系统设置、用户与权限

左侧统一使用全站 10 个产品模块的工作栏。“工作台首页”的下钻页使用可折叠子导航：首页和其他产品模块默认收起，进入工作台下钻页时自动展开，也可以手动收起。

工作台首页采用：

`净回款结果 → 目标与预测差距 → 经营结构 → 过程诊断 → 流程优先级 → 行动 → 结果回看`

所有首页判断都有下钻入口。数据不足时，页面进入“数据条件”，只说明需要补充的数据及用途，不生成缺少依据的长期建议。

`workbench-home-layout-analysis.md` 记录经营口径、归因边界、各页面职责、交互要求和后续数据对象。

## 统一展示规则

- 经营页面顶部必须显示统计周期、对比口径、经营范围和数据截至时间。
- 当前累计目标差额与月末预计缺口必须分开表达。
- 先展示结果，再展示结构、过程原因、流程优先级和行动。
- 缺失数据与业务值 `0` 分开表达。
- 局部覆盖数据不得直接解释全渠道结果。
- 建议必须绑定依据、覆盖范围和可执行动作。
- 任务必须绑定明确业务实体、负责人、截止时间、完成标准与结果回看。
- 正式模式与演示模式共用后端数据契约，不在同一页面混用静态和实时数据。
