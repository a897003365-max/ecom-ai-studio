## 涉及的关键实现点（供排查异常时参考）

- 排序：`useColumnSort` hook + `sortRows`（null/NaN 兜底排末尾）+ `SortHeader` 组件
- 分页：`usePagination` hook（`PAGE_SIZE = 15`，排序变更 resetKey 触发回第 1 页，渲染期 setState 模式）+ `Pagination` 组件（`pageNumbers` 超 7 页折叠省略号）
- 数据条：`.pb-data-bar` CSS（`i` 条 + `b` 文字叠加），花费列覆盖蓝色背景，费比列用默认红色
- 页码栏：`.pb-pagination` CSS，置于 `pb-table-wrap` 外层避免横向滚动连动
- 数据源：`PowerBiPages.promotionSceneDaily`（数仓已迁移的「08-旗舰店推广花费」），与 PBI 同源
